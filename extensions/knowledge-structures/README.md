# Knowledge structures

Knowledge structures is a proposed Abstract language extension for organizing understanding. It builds on [core judgments and contextual identity](../../core/docs/core.md), without changing the existing distinction between identity and detachment.

- [Ontologies](ontology.md): selection of abstractions and downward concretization paths; `*` membership syntax.
- [Domains](domains.md): selection of judgments through contextual concretizations and upward abstraction paths; document-level `#` headers and explicit nested names.

These documents capture the current discussion. Unresolved rules remain explicit. There is no extension implementation yet, and the core parser is not changed to accept its proposed syntax. Attributes and visualization settings are outside this extension.
